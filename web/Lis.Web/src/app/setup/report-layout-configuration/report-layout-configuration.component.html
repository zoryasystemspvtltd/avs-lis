Doctor Signature Configuration

Controls print visibility, horizontal position, and size only. Does not change doctor identity, designation, or signature image source.

Technician Signature Configuration

Controls print visibility, horizontal position, and size only. Uses the Technician signature captured in User Create/Edit. Diagnostic reports resolve the technician from Technician Approval (ReviewedBy).

Radiology workflow does not currently record a technician approver identity. Layout settings can be saved, but Radiology print will not render a technician signature until that identity exists.
